Execução SQL Query e Simulação de Laço com Highlight

O PHP executa o while iluminando cada linha do código em tempo real durante a busca

1. Execução no MySQL $conexao->query()
$sql = "SELECT * FROM usuarios";
2. Código PHP em Execução fetch_assoc()
$sql = "SELECT * FROM usuarios";
$resultado = $conexao->query($sql);
while ($linha = $resultado->fetch_assoc()) {
    if ($linha['id'] == 5) {
        echo "ENCONTRADO!";
        break; // Interrompe a execução
    }
}
